# 第一期（本地可用版）

本文档是第一期范围的唯一入口。第一期不是“最小可跑闭环”，而是用户本人可以在本地长期自用的软件版本，同时内置客户展示所需的 demo 能力。

## 定义

第一期包含两部分：

| 部分 | 目标 | 核心能力 |
| --- | --- | --- |
| 本地可用版 | 用户自己家里真能用 | 单用户、真实 HA 低风险控制、本地 PWA、提醒、记忆、解释型审计 |
| 展示增强 | 给客户 3 分钟看懂价值 | demo mode、决策卡片、trace replay、mock 门锁/camera/OCR 注入 |

mock 能力用于开发、测试和 showcase，不构成本地可用版的验收条件。第一期必须至少有一条真实自用链路：本地入口、真实 HA 只读、低风险 HA 写操作、任务/提醒、记忆和可解释审计。

## 产品目标

第一期要让系统从“架构设计”变成“能住进家里的小而真”：

- 用户可以本地启动服务，连接 Home Assistant，看到系统健康、家庭概览和设备状态。
- 用户可以通过本地 PWA 或本地 Web 入口用自然语言控制低风险设备。
- 系统可以创建、查看、取消和完成一次性提醒或简单事件提醒。
- 系统可以记住用户明确表达的个人低风险偏好，并允许查看、修改和删除。
- 系统可以解释一次动作为什么执行、为什么拒绝、发给了谁、查询了什么 HA 状态。
- 系统可以进入 showcase/demo mode，稳定演示高风险拦截、敏感内容改道、prompt injection 防护和 trace replay。

## 第一期开箱用户故事

1. 本地启动后，用户打开 PWA，看到 HA 连接状态、Agent 状态、今日提醒、待确认事项和最近执行记录。
2. 用户说“把客厅灯调暗一点”，系统解析目标，查询 HA 当前亮度，规范化为绝对亮度，经过 `Tool Safety Proxy` 执行并显示结果。
3. 用户说“晚上 10 点提醒我关窗”，系统创建持久任务，到点后通过本地 PWA 或本地通知提醒用户。
4. 用户说“以后我看电视时客厅灯调到 30%”，系统写入个人私有偏好；用户可以在记忆管理界面查看、修改或删除。
5. 用户说“打开前门锁”，系统不执行真实高风险 HA 写操作，而是展示风险、策略、确认链路和审计记录。
6. 用户打开 showcase mode，一键加载 demo 家庭、mock 设备、mock camera/OCR 事件和 trace 样例，按演示脚本回放客户场景。

## 必须做

- 本地 Python 服务或等价单机服务，可配置、可启动、可重启恢复。
- SQLite 持久化消息、任务、确认、记忆、工具调用、通知决策和审计事件。
- 本地 PWA 或 local web UI，承载聊天、家庭概览、设备卡片、任务、确认、记忆和 trace replay。
- 真实 Home Assistant 只读查询和低风险 allowlist 写操作。
- `Tool Safety Proxy` 作为所有真实副作用的唯一出口。
- 显式 `ToolPolicy` 或等价配置，支持风险等级、allowlist、确认要求和只读模式。
- 低风险灯光控制：开灯、关灯、设置绝对亮度、调暗/调亮规范化。
- 明确标记低风险的 `switch.*` 可按配置放行；中风险设备默认确认或只读。
- 高风险设备默认不执行真实写操作，终态为 `blocked`、`dry_run` 或 `not_supported_in_phase_1`。
- 一次性提醒和简单事件提醒。
- 个人私有、低风险、明确表达的偏好记忆。
- 解释型审计：按 `trace_id` 查看输入、身份、策略、HA 查询、工具调用、输出和拒绝原因。
- showcase/demo mode，包含 demo seed data、演示脚本、重置能力和 mock 事件。

## 可以降档

- 身份与权限降为 `single_user_mode`：单家庭、单 owner、本地 token，保留 `home_id`、`person_id`、`trust_level` 字段。
- 权限系统先用配置文件或 SQLite 表表达，不实现完整 RBAC + ABAC 管理界面。
- 真实微信、飞书、钉钉、完整语音和真实 camera 历史检索后置。
- 确认先使用本地确认页，不做多审批人和跨平台按钮。
- 可观测性先用 SQLite/JSONL 和本地 trace replay，不接外部观测平台。
- 任务 worker 使用单进程轮询和 SQLite lease，不做分布式调度。
- 家庭共享规则、权限记忆、跨用户隐私不自动写入；第一期可用确认或手动配置处理。

## 不做

- 不做多租户和跨家庭身份画像。
- 不做完整 IM 平台矩阵。
- 不做完整音色训练、反重放和真实语音身份认证。
- 不做真实摄像头历史视频检索。
- 不做复杂自动化编排界面。
- 不做完整向量记忆系统。
- 不做完整 `Capability Registry` 或完整 `Home State` 快照。
- 不让 Codex、屏幕按钮、任务 worker 或确认按钮绕过 `Tool Safety Proxy`。
- 不执行门锁、燃气、摄像头隐私、大功率电器等高风险真实写操作。

## 验收标准

- 本地服务能在干净环境中完成初始化、连接 HA 或 demo HA，并显示健康状态。
- 本地 PWA 能完成自然语言低风险灯光控制，并展示 before/after 或 HA 返回语义。
- 重复请求不会重复制造副作用。
- HA 不可用、Codex 不可用、审计不可写时有清晰降级行为。
- 提醒任务能创建、查看、取消、到点触发。
- 个人偏好能写入、读取、修改、删除。
- 高风险动作不会真实调用 HA 写接口，并能显示 `blocked`、`dry_run` 或 `not_supported_in_phase_1`。
- 任意一次低风险控制、拒绝、高风险 dry-run 或提醒触发都能按 `trace_id` 回放。
- showcase mode 可以一键加载、演示、重置。
